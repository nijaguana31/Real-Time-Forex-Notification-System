# Real-Time-Forex-Notifications


A real-time Forex price notification system built with **.NET**, **SignalR**, and **Finnhub API**.  
Authorized clients can subscribe to currency symbols and receive live price updates every 500ms.

---

## 📌 Overview

This project demonstrates a **real-time data streaming architecture** using SignalR.  
It fetches live Forex prices from an external API (Finnhub), stores recent ticks in a database, and broadcasts updates to connected clients.

The system supports:
- Secure client connections
- Symbol-based subscriptions
- Real-time price broadcasting
- Structured logging
- Historical tick retrieval
